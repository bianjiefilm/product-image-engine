# HUI-1699 AI 背景替换收口设计

日期：2026-09-29

## 分类

这是已合入背景替换生成器上的运行与质量收口。不重写报价、指纹、提交判定、选定和导出的原有规则，只补检查、恢复和诚实出图。

## 目标

用户路径是：上传商品照片 → 选择保真模式 → 确认报价 → 生成 → 检查商品 → 选择或导出同一结果。任务指纹继续包含模式、主体保护范围和输入版本。没有真实模型凭证时，结构与状态机可用，但必须标明「真实出图未完成」，不能把任务受理写成生成成功。

## 不做

- 不改 `OpenQuote`、`Fingerprint`、`DecideSubmit`、`Select`、`Export` 的既有判定。
- 不新建文生图引擎，不把保真失败改成创意或整图生成。
- 不编造人民币金额，不把 `production_generation_passed` 或 `billing_passed` 写成 true。
- 不读取或提交模型密钥。凭证只判断是否配置。

## 行为

- 未传保护范围时，HTTP 使用 `logo,packaging_text,spec,structure`。该项与模式、输入版本一起进入既有指纹。
- 创意模式只有 `FEATURE_BG_CREATIVE` 且生成任务可用时才出现在界面。未接通时不渲染选项，服务端仍拒绝创意请求。
- 检查分开记录 Logo、包装文字、规格、结构。任一项失败则质量为 fail，不能选定或导出为可交付版本。相似度分不能把失败改成通过。
- 只有相似度、或分项尚未全部确认：质量保持 unknown，不可交付。
- 1698 主体保真报告若为失败，选定和导出按失败处理。
- unknown、模型失败、额度不足、重复提交和刷新都回到原任务：不第二次调用平台任务，不改变模式，不把失败改成可交付。
- 同一已选定且未失败的输出版本可以重复导出，只增加导出次数。
- 应答记录 model_ref、platform_task_id、output_asset_id、fee_ref。没有这些引用或没有 `PRODUCT_BG_MODEL_CREDENTIAL` 时，`real_generation_completed` 为 false，文案为「真实出图未完成」。

## 界面

工程页背景替换面板沿用现有 Button、Card、Badge，不改全站皮肤。面板只请求 `/api/*`。上传走已有照片与输入接口。刷新页面会载入最近一条任务，不自动重新生成。
