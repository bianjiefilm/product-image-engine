# HUI-1699 AI 背景替换设计

日期：2026-09-27

## 分类

这是在现有产品图工程上新增的背景替换子系统（报价、任务指纹、结果语义）。指挥官已拍板按本规格实施，不另等人确认。

## 目标

完成「已挂接的产品输入 → 保真模式报价 → 确认 → 公共任务或诚实不可用 → 候选 → 选定/导出」结构。默认只改背景和已声明保护区域。创意模式只有在真实生成路径打开时才可选。

## 不做

- 不把生产出图写成已经通过。`production_generation_passed` 恒为 false。
- 不把计费写成已经通过。没有平台报价金额时，界面与 API 只显示「计费待确认」，不编造人民币数字。
- 不新建文生图引擎，不把保真失败静默改成整图生成。
- 不重做上传、尺寸、模板、批量。
- 不依赖正在进行的 HUI-1698 工作区。主体质量默认 `unknown`；本票 HTTP 不接受把质量标成 `pass`。

## 行为

- 开关 `FEATURE_BG_REPLACE` 默认关。关时路由不注册，表现为 404。
- 默认模式 `fidelity`，保护区域默认 `subject`。
- `FEATURE_BG_CREATIVE` 默认关。创意路径还要求生成开关与任务服务可用。否则拒绝创意请求，界面显示未接通。
- 指纹包含租户、工程、输入、输入版本、模式、保护区域、背景意图。同指纹再次提交返回原任务，不第二次调用平台任务。
- 改模式或改输入使未确认报价失效，提交前必须重新确认。
- 生成开关或任务服务不可用：状态 `generation_unavailable`，证据 `none`，质量 `unknown`，不落假图。
- 任务服务超时或 5xx：状态 `unknown`，再次提交仍返回该任务，不重新生成。
- 平台任务成功只表示执行完成，质量仍是 `unknown`，不能当保真通过。
- 质量 `fail` 保持原模式，不可选定为可交付版本。
- 导出使用同一 `output_asset_id` / `output_version`，只增加导出计数，不提交新任务。没有输出资产时导出失败并说明原因。
- 回流失败只重投既有回执，背景替换导出不触发第二次生成。
- 验收样本固定两条：文字/Logo 商品、复杂材质商品。没有真实模型调用时质量 `unknown`，用量「未调用」，费用「计费待确认」。

## 界面

工程详情增加背景替换面板。使用与 shadcn/ui 相同的 Button、Card、Badge 组件接口，样式限定在该面板，避免 Tailwind preflight 改写既有页面。面板必须可见「计费待确认」和「生成质量未验证，不代表生产出图已通过」。
