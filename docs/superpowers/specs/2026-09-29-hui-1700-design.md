# HUI-1700 光影场景收口设计

日期：2026-09-29

总指挥已裁定。本设计只落实这些裁定，不重开问题。

## 分类

这是已合入光影场景上的本地行为收口。PR #11（`f3d7d62389b4101229908945c6ed322ab1841c24`）和 PR #12（`f8e3f2779572e2ef746cf570ae76c99ad2db820f`）已在 main。不重写保真优先，也不重写「保真失败不能靠创意开关绕过」。

## 问题

选择光影或场景之后，报价、确认、失败和未知要在本地钉住。这台机器没有图像模型凭证。真实出图未完成。不得调用供应商，不得把夹具、纯色图或占位图写成模型结果。

## 不做

- 不推翻 `OpenQuote`、`Fingerprint`、`DecideSubmit`、`SubjectGate`、`Select`、`Export` 的既有判定。
- 不把保真失败改成创意或整图生成。创意模式必须显式选择；未接通时界面保持关闭。
- 不用好看背景掩盖 Logo、包装、规格或结构失败。不静默切换模式。
- 不调用图像供应商。没有 `PRODUCT_LIGHT_MODEL_CREDENTIAL` 时不提交平台任务。
- 不登记夹具图，不生成占位图，不把输出编号写成模型结果。
- 不把 `charged` 写成 `false` 或 `true`。没有账单客户端时保持 JSON `null`。
- 不把 `billing_passed` 或 `production_authorized` 写成 true。
- 不宣称光照方向已经用固定实拍样本验证。
- 不开始 HUI-2232、HUI-1702、HUI-1991。
- 不新引入视觉系统。面板继续用现有 Button、Card、Badge。
- 不绑定 18101，不占用 18541、18542、18543。

## 行为

- 选择光影意图并生成报价后，`quote_status` 为 `unconfirmed`。确认后为 `confirmed`。模式、输入或光影意图变化仍使未确认报价失效。
- 确认前提交返回冲突，不调用任务，不出图。
- 没有图像模型凭证时，提交后状态保持 `failed`，不调用供应商。文案含「真实出图未完成」。`real_generation_completed` 为 false。
- 凭证字符串不回传、不入库。凭证只表示是否配置。
- 失败和 `unknown` 不覆盖用户后来选定的输出版本：已选定的 `output_version`、`output_asset_id`、`selection` 保持不变。平台返回的资产编号仍然不是模型结果。
- 没有凭证时，刷新和再次提交不调用供应商，也不调用账单客户端。失败记录不再向供应商核对。`charged` 保持 JSON null。
- 有凭证时，unknown 的再次核对只读已有任务状态，不新提交任务，不调用账单，不覆盖已选定版本。
- `billing_passed` 为 false。`production_authorized` 为 false。`production_authorization` 为 `NOT_AUTHORIZED`。
- 应答可追溯输入版本、模型引用、模型指纹、任务指纹和平台任务编号。没有模型调用时模型引用和模型指纹为空，不编造。
- 创意开关即使打开，没有凭证或生成任务不可用时，`creative_available` 仍为 false。

## 界面

工程页光影面板沿用现有 Button、Card、Badge。可见报价状态、真实出图未完成、版本、模型和任务指纹。不画图片。创意未接通时不提供可选创意。页面只请求 `/api/*`。
