# HUI-1701 文生图可信成功结果

日期：2026-09-29

总指挥已裁定。本设计只落实这些裁定，不重开问题。

## 问题

PR #15 合入后，文字描述可以开任务，但展示层把每条结果都固定成失败并清空资产。这样能挡住假图，也把一切成功永久关掉了。没有供应商凭证时必须继续失败关闭。有服务端自己登记、并且字节对得上的结果时，列表、详情和下载要能打开那张图。

这张图不是模型出图。这台机器没有图像模型凭证。

## 不做

- 不调用图像模型，不生成一张图然后把它叫做模型结果。
- 不把客户端自报的成功、任意 asset id、别的租户的资产显示出来。
- 不把 `charged` 写成 `false` 或 `true`。应答里保持 JSON `null`。
- 不把 `billing_passed` 写成 true，不把 `production_authorized` 写成 true。
- 不把 Billing 标成 PASS。作品完成时的结算文案只用刚合入的 Reconcile：「作品完成待核对」。
- 不发送 Hold、Release、Settle 的真实资金 HTTP。
- 没有实物参考时不宣称主体保真。文生图是概念输出。
- 不换现有界面组件。前端是 Next.js，不是 Vue。结果表面继续用现有 shadcn 风格的 Button、Card、Badge。
- 不绑定 18101。不改 HUI-2232、HUI-1700、HUI-1702。

## 可信展示

一张图同时满足下面全部条件，列表、详情和下载才打开它：

1. 任务状态是 `completed`。
2. 任务属于当前 tenant 和当前 project。
3. 资产上记下的输入版本与任务当前输入版本一致。输入版本是创建时的指纹（租户、工程、文字描述）。
4. 资产由服务端登记，且文件字节的 SHA-256 与登记一致。
5. `origin` 是 `fixture`。本轮没有别的来源可以展示。供应商回执和客户端编号都不是来源。

缺任何一条：`show_image` 为 false，应答里的 `output_asset_id` 为空，下载不返回字节。哈希不符返回完整性拒绝，不把字节写进响应。别的租户与不存在一样，是 404。

## 夹具登记

测试通过服务端动作登记夹具，不由客户端声称成功。

- 路由 `POST /api/v1/projects/{id}/text-images/{jobId}/fixture` 只在 `TEXT_IMAGE_FIXTURE_REGISTER` 打开时注册。默认关闭。生产配置不打开它。
- 请求体里的 `fixture` 字段必须包含 `fixture`。测试名也写 Fixture。这是夹具，不是模型结果。
- 服务端解码图片、嗅探并解码、自己计算 SHA-256、自己分配资产编号。客户端给的 asset id 不作数。
- 登记把任务写成 `completed`，`origin=fixture`，并保存字节。失败或待确认的任务不能借这条路径改成完成。
- 同一个幂等键（指纹）始终返回原任务，不新生成。同一任务上再登记不同字节，不覆盖第一次的资产。
- 用户选定版本之后，晚到结果不能换掉 `selected_version`。选定前的第一次登记同样不被后来的字节替换。
- 创建应答丢失后，用同一文字描述再创建，按原键查回同一条任务。

没有打开夹具开关时，这条路由不存在。没有凭证的提交仍是失败或待确认，`show_image` 为 false，文案含「真实出图未完成」。`real_generation_completed` 恒为 false。凭证字符串不回传、不入库。

## 计费和生产授权

生成完成不等于已结算。

- `charged` 为 JSON null。
- `billing_passed` 为 false。
- `production_authorized` 为 false，同时给出 `production_authorization=NOT_AUTHORIZED`。
- 状态完成且没有账单时，`settlement` 为「作品完成待核对」。未完成时保持 `unknown`，计费文案仍按连接状态（配置缺失或未实现）。
- 夹具登记、列表、详情、下载、选定都不调用 Hold、Release、Settle。

## 概念输出

没有 `photo_asset_id` 时，界面写「概念输出，不宣称主体保真」。`subject_protected` 保持 false。有照片也不在本结果里宣称已经保护。

## 界面

工程页和开始页的文字面板继续用现有 Button、Card、Badge。

- 可信夹具：显示图片，替代文字说明这是服务端登记的夹具，不是模型出图，并同时显示「真实出图未完成」和「作品完成待核对」。
- 没有凭证、或信任条件不成立：不画成功图。
- 面板正文不出现「已结算」。

图片地址走本应用 BFF 的下载代理，不把平台地址交给浏览器。
