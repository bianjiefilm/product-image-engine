# HUI-1991 产品图报价 / 预占 / 结算 / 查回装配

## 问题

PR #14 只证明了本地消费端：付款主体、人民币文案、充值返回和五级口径。它用写死的 `charged=false` 和 `BillingConnected=false` 表示「没扣钱」。这不能证明资金安全。生成完成也不等于已结算。

本票把报价、预占、结算、查回装到已经发布的 public-ai 消费接口上。payer 只来自服务端身份和已授权的组织。本轮不对客户资金做扣款。

## 不做什么

- 不在本产品建钱包、充值表或余额副本。
- 不用订单服务款扣图像费，不把联系人手机号当平台账号。
- 不改 public-ai、GoBoost、leads、touch。HUI-2204 的接口只消费已经存在的部分。
- 不重写文生图成功展示（HUI-1701）。不出图、不把失败改成成功。
- 背景替换在没有真实账单时保持 `billing_passed=false`，没有真实出图时保持「真实出图未完成」。
- 不把 Integration、Billing 或 Production Authorized 标成通过。渠道采购没有，Channel Billing 为 N/A。

## 付款主体

服务端用工程上已经保存的 `source_type` / `source_ref` / `tenant_id`，加上令牌里的 `account_id` 和 `org_payers`。

- 独立工程默认个人付款。
- 工程来源是订单或活动时，只用令牌里授权、且租户等于该工程租户的组织付款主体。
- 请求体里的 `payer_account_ref`、`source_tenant_id`、`source_type` 不能改 payer。带了不同的付款账号就拒绝。
- 工程只在调用方有成员资格的租户里可读。A/B 租户不能互读。
- 手机号形状的账号拒绝。

用户改的是用量，不是付款人：张数、分辨率、能力。这些变化必须重新确认报价。价格版本由服务端固定为 `pricing-2026-09`，不采用请求体里的版本。

## 平台装配

消费已发布的 `github.com/bianjiefilm/public-ai/sdk/go` v0.1.0。

| 动作 | 行为 |
| --- | --- |
| 报价 | 先调用已有 `POST /internal/v1/billing/unified/usage` 登记用量，再调用目录里的 `billing.quote`。可以打到真实平台。 |
| 余额 | 只读已有 `GET /internal/v1/billing/unified/accounts`。读不到就保持未知，不当成余额充足。 |
| 预占 `billing.hold` | 本轮真实端口不发送。测试双记录预占。 |
| 结算 `billing.charge` | 本轮真实端口不发送。 |
| 释放 | 真实端口不发送。测试双释放自己记下的预占，结束时净额为零。 |
| 查回 | 已保存的任务编号走目录里的 `task.get`。没有账单就保持未知，不编造成功。 |

连接状态：

- 计费开关、地址或令牌缺了：`配置缺失`。不发请求。
- 平台路由不存在（`billing_route_not_found`）或端口没装上：`未实现`。
- 平台不可达：报不可达，不编报价。

地址必须是 loopback，跟消费包一致。用量登记不在 v0.1.0 目录里，所以按同一套应用令牌头调用已经存在的 HTTP 路径。登记失败若是路由不存在，就报「未实现」，不本地算一个价。

## 生成和账务

确认报价只表示用户接受当前指纹。确认本身不预占、不结算。

余额不足只给统一 Billing Center 的 `return_target` 和 `quote_ref`。从充值页回来只重读余额，`generate_allowed` 仍为假，必须重新确认。

超时、未知、刷新先查已保存的任务。请求体里的新任务号或新幂等键不能另开一条。不重复生成，不重复扣费。

作品已经完成但没有账单：`作品完成待核对`，`billing_passed` 仍为假，不重新生成。

应答里的 `charged` 为空。不用 `false` 证明账本已核对。没有账单时 `settlement` 为 `unknown`。

## 界面

Next.js。报价面板继续用现有 shadcn 风格的 Badge/Button，不换整站。

文生图面板只改计费文案来源：展示服务端的连接状态或「本次预计 ¥…」。不展示图片，不接受客户端自报的金额。背景替换透传「配置缺失 / 未实现 / 作品完成待核对」，没有人民币的自报文案仍然不当成报价。真实出图文案不变。

## 完成等级

| 级 | 本票 |
| --- | --- |
| Implementation | 本地测试能证明装配、拒绝和净额为零 |
| Integration | 没有打到运行中的平台就是 UNKNOWN |
| Billing | 没有可复算的真实扣款，UNKNOWN |
| Channel Billing | N/A |
| Production Authorized | 否 / NOT_AUTHORIZED |
