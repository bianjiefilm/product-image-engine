# HUI-1700 光影场景设计

日期：2026-09-27

## 分类

这是在现有产品图工程上新增的光影场景子系统，沿背景替换的报价、指纹和任务结构。指挥官已指定约束并要求实施。

## 目标

完成「已挂接的产品输入 → 保真模式报价 → 确认 → 公共任务或诚实失败/待核对」。默认只改光影和氛围，主体保护走 HUI-1698 的结论，不能绕过。

## 不做

- 不把生产出图写成已经通过。`production_generation_passed` 恒为 false。
- 不把计费写成已经通过。没有平台报价金额时只显示「计费待确认」。
- 不调用计费扣款，不伪造供应商回执。填好的输出编号不能当回执。
- 没有真实供应商时，结果是 `failed` 或 `unknown`（待核对）。失败记录不能改成已验证产品图。
- 客户端不能自报主体保护通过。没有保真通过且没有供应商回执时，不能选定或导出为已验证产品图。
- 不新建文生图引擎。保真失败后不能静默改成整图生成。

## 行为

- 开关 `FEATURE_LIGHT_SCENE` 默认关。关时路由不注册，表现为 404。
- 默认模式 `fidelity`，保护区域默认 `subject`。
- `FEATURE_LIGHT_CREATIVE` 默认关。创意路径还要求生成开关与任务服务可用。
- 指纹包含租户、工程、输入、输入版本、模式、保护区域、光影意图。同指纹再次提交不第二次调用平台任务。
- 改模式、改输入或改光影意图使未确认报价失效。
- 生成开关或任务服务不可用：状态 `failed`。任务服务超时或 5xx：状态 `unknown`。
- 平台返回的 `asset_id` 不写入输出，也不当作回执。
- 选定和导出前读取同一输入的主体保护报告。失败或缺失都拒绝已验证产品图。
