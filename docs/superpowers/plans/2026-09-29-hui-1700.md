# HUI-1700 光影场景收口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 钉住光影场景的报价、确认前不出图、选定版本不被失败覆盖，以及没有账单客户端时的计费字段。

**Architecture:** 沿已合入的光影任务。没有图像模型凭证时提交保持失败且不调用供应商。应答补上可追溯字段，不新增出图引擎。

**Tech Stack:** Go、SQLite、Next.js 现有 Button/Card/Badge。

**Spec:** `docs/superpowers/specs/2026-09-29-hui-1700-design.md`

## Global Constraints

- 没有 `PRODUCT_LIGHT_MODEL_CREDENTIAL` 时不调用供应商，状态 `failed`，文案「真实出图未完成」。
- `charged` 为 JSON null。`billing_passed` 为 false。`production_authorized` 为 false。`production_authorization` 为 `NOT_AUTHORIZED`。
- 不把夹具、纯色图或占位图写成模型结果。`real_generation_completed` 为 false。
- 不推翻保真优先，保真失败不能靠创意开关绕过。创意未接通时不可选。
- 失败和 unknown 不覆盖已选定的 `output_version`。刷新和重试不重复扣费。
- 不绑定 18101。服务只用 18551 和 18552。Go 测试加 `GOWORK=off`。
- 不开始 HUI-2232、HUI-1702、HUI-1991。不宣称光照方向已用实拍样本验证。
