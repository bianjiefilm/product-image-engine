# HUI-1991-r3 消费端夹具报价 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在已有消费端上标明未发送扣费，服务端解析付款主体，并用环回夹具证明 A/B 余额隔离。夹具不是 Billing PASS。

**Architecture:** `billconsume` 继续只组装配额事实和指纹。`billassemble.Live` 可以报价和只读余额，不发送预占、结算、释放。环回夹具只在测试里听空闲端口。HTTP 和开始页沿用现有 Badge/Button，不换组件库。

**Tech Stack:** Go 1.26、已发布的 `platformconsumer` v0.1.0、SQLite、Next.js 15、vitest。

**Spec:** `docs/superpowers/specs/HUI-1991-r3.md`

## Global Constraints

- `GOWORK=off`。不改 public-ai、GoBoost、leads、touch、画师和光影失败关闭。
- 不建钱包或充值表。JSON `charged` 为 null。`billing_passed` 为 false。`production_authorized` 为 `NOT_AUTHORIZED`。
- 没有现场 `PRODUCT_BILLING_BASE_URL` 与测试令牌时不打真实计费。夹具用 `127.0.0.1:0`，避开 18084、18120、8080、8081、5173、18101。
- 产品应答的 Integration / Billing 仍是 `UNKNOWN`。报告里的 Integration PASS 只表示适配器对上了夹具。
