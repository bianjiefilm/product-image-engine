# HUI-1991 报价装配 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 把产品图的报价、预占、结算和查回装到已有平台接口上，payer 只来自服务端，本轮不扣客户资金。

**Architecture:** `billassemble` 定义端口。真实端口只发送用量登记、`billing.quote`、余额只读和 `task.get`。预占、结算、释放在真实端口不发送；测试双记录预占并在结束时释放到净额零。HTTP 消费、文生图和背景替换只改计费文案和查回，不改成功出图。

**Tech Stack:** Go 1.26、`platformconsumer` v0.1.0、SQLite、Next.js 15、vitest。

**Spec:** `docs/superpowers/specs/2026-09-29-hui-1991-design.md`

## Global Constraints

- `GOWORK=off`。不改 public-ai、GoBoost、leads、touch。
- 不建钱包或充值表。不用订单款。不用手机号当账号。
- 真实端口不调用 hold、charge、refund。
- `charged` 不为了证明安全而写死 `false`。没配报「配置缺失」，没实现报「未实现」。
- 背景替换保持「真实出图未完成」和 `billing_passed=false`，除非查回里有真实账单。
- 五级里 Integration / Billing 保持 UNKNOWN，Channel Billing 为 NOT_APPLICABLE，Production Authorized 为 NOT_AUTHORIZED。
- 价格版本固定 `pricing-2026-09`。
