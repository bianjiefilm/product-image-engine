# HUI-1704【FEAT-0205】批量生成 — 实施计划

- 分支:`hui-1704-feat-0205-batch`(基线 main=`f994b7f`,I0+I1+1703 均已并)
- 票面:批量上传产品,批量生成多场景多尺寸图片。本票是**批次编排层**:批量创建工程/输入
  → 批量提交生成 → 批量收集。生成语义(场景/模型/费用)沿 I0 既有链路,不重写;
  worker 不可用时批次**如实失败/阻塞,不伪造成功**。
- 指挥者预答已全部采纳(见下);阻塞自决记录于 REPORT.md「自决与偏差」。

## 1. 设计定稿

### 1.1 持久模型(migration 0004_batch.sql,全 additive)

- `batches(id, tenant_id, created_by, project_id→projects, name, status, preset_summary JSON, error_code, created_at, updated_at)`:
  - status(拍板枚举):`pending|submitting|running|completing|completed|completed_with_failures|failed|cancelled`。
  - `preset_summary` = 所选场景×尺寸意图:`{"scenes":[…],"usage_note":"…","presets":[…],"finalize_with_variants":bool}`。
  - 自决加列 `error_code`:批次级失败原因(`generation_disabled`/`task_unavailable`)——拍板枚举无
    `blocked` 批次态,「批次=blocked 如实」由 `failed+error_code` 落地,不改枚举。
  - `counts` 不落列:由 batch_items 聚合派生(读时计算,不可能漂移=更如实),API 统一返回。
- `batch_items(id, batch_id→batches, tenant_id, project_id, input_ref→project_inputs, input_sha256, input_name, input_size, task_ref 可空, status, error_code 可空, output_id, size_variant_ids JSON 可空, variants_note, attempts, created_at, updated_at)`:
  - status(拍板枚举):`pending|submitted|succeeded|failed|blocked|cancelled`。
  - 幂等键(拍板):`UNIQUE(batch_id, input_sha256)`——同批次同内容输入只有一个 item。
- 批量上传走**既有 upload 输入门**:每个文件先经 `sizeadapt.DecodePNG`(魔数+≤8MiB+真解码+像素上限)
  校验 → `Uploads.RegisterAsset` 拿平台 asset_id(网络调用在事务外)→ 单事务建 project+inputs+batch+items。

### 1.2 生命周期(全部服务端状态机;task 幂等键=batch_id+item 输入 sha256+attempt 序号)

- **创建** `POST /api/v1/batches`(多文件 data_b64+场景/预设选择)→ 建 1 个工程(自决:一批次=一工程,
  文件=工程多输入,复用现有域模型)+ 逐 item 登记 → batch=`pending`、items=`pending`。
  不做生成门(验收:开关 off 也要创建成功)。
- **提交** `POST /api/v1/batches/{id}/submit`:
  - `GenerationUsable()` 不过 → 全部 pending item 置 `blocked`(error_code=`generation_disabled`),
    batch=`failed`+error_code,如实返回 200+终态(不伪造、不静默)。
  - 门过 → batch=`submitting`;逐 item 提交(**并发上限 4,进程内信号量**,chan struct{} 超出排队);
    受理 → `submitted`(task_ref,attempts+1);`ErrUnavailable` → `blocked`(error_code=`task_unavailable`);
    其他 task 拒绝 → `failed`(error_code=`task_rejected`)。收尾:有 submitted → `running`,否则 `failed`。
  - task 幂等键:`batch-{batchID}-{sha256前16}-a{attempts}`(同批次同输入同序号平台侧幂等;
    重试递增 attempt → **新 task 引用**,满足验收)。
  - 再次 submit 允许重试 `pending|blocked` 的 item(先过门,非盲目);cancelled/completed 批次 409。
- **收集** `POST /api/v1/batches/{id}/collect`(手动;web 面板轮询之。「查询自动推进皆可」拍板取手动,
  GET 零副作用):对 `submitted`(及 `blocked 且有 task_ref`——成果登记失败重试)逐 item:
  - `TaskClient.Status`(新增,PROVISIONAL `GET /internal/v1/tasks/{id}`):
    `succeeded` → 取 result.data_b64(测试链路合法 PNG)→ **既有 outputs 登记路径**(PNG 门+sha256+
    RegisterAsset+CreateOutput,同内容幂等)→ 可选按预设生成变体(见 1.3)→ item=`succeeded`;
    `failed` → item=`failed`(error_code=`task_failed`);pending/running → 保持;查询不可达 → 保持
    (稍后再 collect);**任务成功但成果不可用(缺 data_b64/坏 PNG/超 8MiB)→ item=`failed`
    (error_code=`invalid_result`),绝不伪造**;成果登记失败 → item=`blocked`(error_code=`output_register_failed`,
    可再 collect)。
  - 全部 item 到终态后批次终态聚合(纯函数 `nextBatchStatus`,单测钉死):
    全 succeeded→`completed`;有 succeeded 有 failed→`completed_with_failures`;全 failed/blocked→`failed`;
    全 cancelled→`cancelled`。
- **重试失败** `POST /api/v1/batches/{id}/retry-failed`:仅 `failed` item 重新提交(新 task 引用);
  先过生成门,门不过 → 503 点名开关(**提示先修配置**);`blocked` 不盲目重试,响应附提示
  「blocked 项请先修复配置后用 submit」。
- **取消** `POST /api/v1/batches/{id}/cancel`:**owner only**(created_by≠当前用户 → 403 `not_owner`);
  仅 `batch=pending` 或(`failed` 且全部 item∈{blocked,cancelled})可取消 → items 全 `cancelled`、
  batch=`cancelled`;已提交任务不撤单(本就无 submitted 项可取消;若未来出现则由收集按事实对齐)。
- 权限:批次全部端点按 principal 租户作用域(跨租户=404,与工程域同口径);取消另加 owner 判定。

### 1.3 「多场景多尺寸」映射(拍板)

- **场景** = 提交参数:沿 I0 task 提交形状(SUBMIT 信封 PROVISIONAL 不变更),场景列表放进
  payload:`{project_id, platform_asset_id, usage_note, scenes:[…], batch_id, batch_item_id}`。
- **尺寸** = sizeadapt 组合:item succeeded 后,若 `finalize_with_variants=true` 且 `FEATURE_SIZE_ADAPT=on`
  且预设集已装配 → 对登记成果按所选预设逐一生成变体,复用 1703 幂等(同
  `(source_output_id, preset_name, variant_mode)` 唯一键,重复 collect 幂等返回既有变体);
  开关 off/预设未选 → 忽略该参数并在 item.variants_note 如实标注 `skipped: …`。
