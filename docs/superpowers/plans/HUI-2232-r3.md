# HUI-2232-r3 产品价值检查记录 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做一个只存在于内存中的产品价值检查记录器：缺配置得到 `配置缺失`，未知观测留在记录上，但记录永远不通过产品价值门。

**Architecture:** `qualitygate.Build` 纯函数产出记录或固定错误。`CanonicalJSON` 拒绝一切成功形态。`Registry.Submit` 在必填字段齐全时按逻辑编号保存第一份记录，回放返回副本且不增加检查。不接入 HTTP、存储、出图或供应商。

**Tech Stack:** Go 1.26，标准库（`crypto/sha256`、`encoding/json`、`sync`）。

**Spec:** `docs/superpowers/specs/HUI-2232-r3.md`

## Global Constraints

- 只新增 `server/internal/qualitygate` 与本规格、本计划。不改 videofixture、showcasevideo、httpapi、lightscene、textimage、go.mod、go.sum。
- 状态常量是 `真实出图未完成`。`quality_passed`、`generation_passed`、`billing_passed` 保持 false。
- `provider_calls` 是 0，`charged` 是 JSON null，`production` 是 `NOT_AUTHORIZED`。
- 缺租户、工程、摘要、质量观测、生成观测或费用观测时返回 `配置缺失` 和 nil 记录，且不入库。配置缺失先于回放，也先于口径拒绝。
- 禁用产出短语：`工程通过`、`质量通过`、`Billing PASS`、`真实出图完成`。错误文本和规范 JSON 都不得含有它们。`billing pass` 大小写不敏感。
- 未知观测原文留下。调用方不能翻转三枚 false 旗标。
- 同一逻辑编号回放同一记录，不建第二次检查。同一输入的规范 JSON 字节相同。
- 六枚标签顺序固定：`Engineering for the recorder test only`、`Browser NOT_RUN`、`Service NOT_VERIFIED`、`Billing NOT_VERIFIED`、`Production NOT_AUTHORIZED`、`Human UNKNOWN`。
- 不联网，不占端口，不访问数据库，不生成图片。标准库 only。
- 测试命令：`cd server && GOWORK=off go test -count=1 ./internal/qualitygate/`。不跑整个模块。
- 产品价值门未通过。真实出图未完成。

func TestConcurrentReplayStoresOneCheck(t *testing.T) {
	reg := NewRegistry()
	in := Input{LogicalID: "same", TenantID: "ten", ProjectID: "prj", Digest: "d", Quality: "unknown", Generation: "unknown", Fee: "unknown"}
	var wg sync.WaitGroup
	errCh := make(chan error, 32)
	for i := 0; i < 32; i++ {
		wg.Add(1)
		go func() {
			defer wg.Done()
			rec, err := reg.Submit(in)
			if err != nil || rec == nil || rec.QualityPassed || rec.Status != "真实出图未完成" {
				errCh <- err
				return
			}
			errCh <- nil
		}()
	}
	wg.Wait()
	close(errCh)
	for err := range errCh {
		if err != nil {
			t.Fatal(err)
		}
	}
	if reg.Checks() != 1 {
		t.Fatalf("并发回放建立了多次检查: %d", reg.Checks())
	}
}
