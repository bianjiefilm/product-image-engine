# HUI-1703【FEAT-0204】电商尺寸适配 — 实施计划

- 分支:`hui-1703-feat-0204-ecom-sizes`(基线 main=6f8683e,I0+I1 底座)
- 票面:自动适配各电商平台主图/详情页/广告尺寸。**纯确定性图像处理**——不调用 AI 模型、
  不产生 Task/Billing 费用、不触碰生成开关(代码路径零调用边,grep 断言)。
- 指挥者预答已全部采纳(见下);阻塞自决记录于 REPORT.md「自决与偏差」。

## 1. 设计定稿

### 1.1 纯函数模块 `server/internal/sizeadapt`(新包)

- 依赖:stdlib `image`/`image/png`/`image/jpeg` + `golang.org/x/image/draw`
  (CatmullRom 高质量缩放;唯一新增依赖)。**禁止 import internal/platform、task、billing**;
  包内自带 `TestNoForbiddenImports`(go/parser 解析本包全部源文件断言 import 白名单)。
- 变换模式(两元,拍板):
  - `pad`:等比缩放(scale = min)→ 白底画布居中;透明通道与白底合成(输出恒为不透明)。
  - `cover`:等比缩放(scale = max)→ 居中裁切填满;同样先与白底合成(压平 alpha,确定性输出)。
  - `height==0` 约定(仅 pad):「fit-width」详情页语义——宽缩放到精确值,高按源等比,不纵向填充
    (覆盖拍板示例 `tmall_detail_w790(790 宽等比)`;schema 仍为三元组,文档化哨兵值,非业务硬编码)。
- 输入解码门(fail-closed,复用 I1 outputs 域口径):PNG 魔数、≤8 MiB、png.Decode 成功;
  解码后上限:单边 ≤16384px 且总像素 ≤40M(防解压炸弹,400 拒绝)。
- 输出:PNG(默认)或 JPEG(quality 固定 90,拍板「可选」档);透明像素压平为白底后 JPEG 编码。
- 确定性:同一输入+同一预设 → 字节级相同输出(测试断言两次编码 sha256 相同)。
- 缩放取整:缩放后尺寸四舍五入、居中偏移向下取整——纯函数,单测钉死。

### 1.2 预设矩阵 `presets.json`(go:embed + 可覆盖)

- schema:`{"presets":[{"name","width","height","mode","label"}]}`,三元组 + 展示名;
  加载即校验(name `[a-z0-9_]{2,64}`、1≤w≤16384、0≤h≤16384 且 h=0 仅限 pad、mode∈{pad,cover}),
  非法即拒绝(fail-closed,同 appregistry 先例)。
- 内嵌预设(README 注明「公开常见规格整理,商家可自定义覆盖,以各平台当时官方要求为准」):
  `taobao_main` 800×800 pad、`tmall_main` 800×800 pad、`tmall_detail_w790` 790×0 pad(fit-width)、
  `jd_main` 800×800 pad、`pdd_main` 750×750 pad、`douyin_ad` 1080×1440 cover、
  `xhs_cover` 1080×1440 cover、`generic_square_1024` 1024×1024 pad。
- 覆盖:`PRODUCT_SIZE_PRESETS` env 指向自定义 JSON(先例:PRODUCT_REGISTRY_MANIFEST);
  未配置用内嵌。装配进 `httpapi.Server.Presets`;nil 时 main 缺省内嵌(测试可注入)。

### 1.3 持久模型(migration 0003_size_variant.sql,additive)

- `project_outputs` 加列:`kind TEXT NOT NULL DEFAULT 'result'`(`result`|`size_variant`)、
  `source_output_id`、`preset_name`、`variant_mode`、`variant_width`、`variant_height`(默认空/0)。
- 唯一键(拍板):`CREATE UNIQUE INDEX … ON project_outputs(source_output_id, preset_name, variant_mode)
  WHERE kind='size_variant'`(部分索引;result 行三列皆空值不参与)。
- `size_variant_blobs(variant_id PK REFERENCES project_outputs(id), content BLOB)`:
  本地保存变体字节。**自决记录**:I1「本产品不存文件」指用户素材/成果登记走平台 upload 引用;
  但票面 web 面板要求「下载」,平台 upload client 无下载端点,故变体(本功能自产衍生件、
  ≤源 8 MiB 约束、唯一键限流)本地留字节以支撑零依赖下载;源素材仍零字节。
- store 新增(`store/sizevariants.go`):`CreateSizeVariant`(输出行+blob 单事务)、
  `FindSizeVariantByKey`、`ListSizeVariants`、`GetVariantBlob`(join 校验租户)、
  `GetOutputUnscoped`/`GetProjectUnscoped`(仅用于 403/404 分类,注释红线:禁止把行数据返回给非属主)。

### 1.4 端点(server,FEATURE_SIZE_ADAPT 默认 off)

- 开关:`FEATURE_SIZE_ADAPT`(config 新字段,默认 off)。off 时路由**不注册**(404 不可见,拍板原文);
  on 时:`GET /readyz` gates 增加 size_adapt enabled 展示。
- 权限(沿用工程门控 + 验收 403):目标工程/输出/变体按 id 全局存在但租户不符 → **403 tenant_mismatch**
  (同 handoff 错租户 403 先例);不存在 → 404。owner/成员维度:本系统现有门控即租户门控
  (工程无成员表),租户归属即授权,报告记录。
- 端点:
  - `GET /api/v1/size-adapt/presets` — 当前生效预设列表(BFF 面板渲染源)。
  - `POST /api/v1/projects/{id}/size-adapt` — body `{source_output_id, preset_name, format?, data_b64}`;
    校验链:工程(租户/403)→ 源输出存在且属于该工程 → sha256(data_b64)==源输出 result_sha256
    (「输入仅接受项目已有 outputs」的密码学落实)→ PNG 门 → 变换 → upload RegisterAsset 登记 →
    落 kind=size_variant 行+blob。唯一键幂等:同键已有 → 200 `{variant, duplicate:true}`,不重复产文件;
    并发竞态由 UNIQUE 兜底 → 重读返回既有。format(png 默认/jpeg q90)不参与唯一键(拍板键三元),
    同键首产格式为准(报告记录)。
  - `GET /api/v1/projects/{id}/size-adapt` — 变体列表(新→旧)。
  - `GET /api/v1/projects/{id}/size-adapt/{variantId}/download` — blob 直出
    (Content-Type image/png|image/jpeg,Content-Disposition attachment)。
- 与生成链零耦合:不 import TaskClient/BillingClient 调用边;不读 GenerationUsable/BillingUsable;
  `FEATURE_GENERATION_ENABLED=off` 不影响本功能(HTTP 测试断言)。

### 1.5 web/BFF(零业务判断)

- BFF 新路由(只转发):`/api/size-adapt/presets`(GET)、
  `/api/projects/[id]/size-adapt`(GET/POST)、`/api/projects/[id]/size-adapt/[variantId]/download`
  (GET 二进制透传:不走 callServer 的 JSON 解析,流式转发 + attachment 头)。
- 工程详情页「尺寸适配」面板:先探 presets(404=开关 off → 面板不渲染,拍板「on 可见」);
  on 时:预设勾选列表、源输出下拉(限 PNG)、格式选择、生成按钮 → 变体表格
  (缩略名+预设+尺寸 WxH+模式+大小+下载链接)。
- vitest:`bff-sizeadapt.test.ts`(presets 透传、生成 201/200 幂等、列表、下载头透传、off 404 透传)。
