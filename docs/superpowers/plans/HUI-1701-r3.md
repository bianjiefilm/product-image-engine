# HUI-1701-r3 服务端任务资产 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 服务端自己轮询到的已完成任务，只要资产编号和字节都是服务端持有的，列表、详情和下载就打开那张图；客户端编号、缺凭证和未结算都不能变成成功。

**Architecture:** `textimage.AcceptServerTask` 只看任务状态、服务端资产编号和服务端字节。凭证布尔值不参与通过。存储用单独的完成写入，通用更新仍拒绝把状态写成成功。刷新在通过后保存字节。没有可解码的任务载荷时调用 `PaintLocalTest`，不改平台客户端的返回值。

**Tech Stack:** Go、SQLite、Next.js、现有 Button/Card/Badge。

**Spec:** `docs/superpowers/specs/HUI-1701-r3.md`

## Global Constraints

- 光影失败关闭不改。缺凭证不是光影成功。
- `charged` 为 JSON null。`billing_passed` 为 false。`production_authorized` 为 false。`production_authorization` 为 `NOT_AUTHORIZED`。
- 没有账单的完成态结算文案是「作品完成待核对」。
- 无模型调用时文案是「真实出图未完成」。`real_generation_completed` 为 false。
- 没有实物参考时不宣称主体保真。
- 测试命令带 `GOWORK=off`。不绑定 18084、18120、8080、8081、5173。
- 不伪造平台成功。不把凭证写进应答或日志。
